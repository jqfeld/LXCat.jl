LXCat.jl

Read, write and resolve cross-section data in the LXCat text format.

Installation

]add https://github.com/jqfeld/LXCat.jl.git

Usage

using LXCat

# load_database() returns an array of CrossSections
cs_array = load_database("/path/to/LXCat/file.txt")

cs_array[1](1.0) # returns cross-section in m^2 for energy 1.0 eV

# Outside the tabulated energy range the cross section is not extrapolated by
# default and evaluating it throws; opt in per database:
cs_array = load_database("/path/to/LXCat/file.txt";
  extrapolation=ExtrapolationType.Constant)  # or .Extension for linear

# write_database() is the inverse of load_database(): same collision data,
# comments and timestamps, not necessarily the same byte formatting.
write_database("/path/to/output.txt", cs_array)

Naming the species

A cross section's collision carries a reaction field. Straight from a file it holds an LXCatReaction, the raw label strings kept verbatim:

cs = cs_array[1]
reaction(cs)        # LXCatReaction("e", "O2", "O2(a1Dg)")
target_label(cs)    # "O2"

LXCat state notation is not standardized — each database picks its own names — so those labels are not parsed. For real PlasmaSpecies species, supply a map and resolve:

using PlasmaSpecies   # loads the extension

reactions = Dict(
  ("O2", nothing)        => p"e + O2 --> e + O2",
  ("O2", "O2(a1Dg)")     => p"e + O2 --> e + O2[a1Dg]",
  ("O2", "O(3P)+O(3P)")  => p"e + O2 --> e + 2O[3P]",
)

resolved = resolve(cs_array, reactions)

resolve throws and lists every gap at once, so a forgotten state cannot slip through as a rate coefficient that matches nothing downstream. print(reaction_template(cs_array)) emits a pasteable skeleton covering every distinct (target, product) pair in the database, and missing_reactions(db, reactions) reports what a map does not yet cover.

The reaction type being a type parameter, a function that needs real species can say so and never receive an unresolved database:

rate(c::AbstractCollision{ReactionFormula}, eedf) = ...

Full reactions also express what a single product label cannot: dissociation into two of the same species (2O[3P]) or into two different ones, and vibrational transitions, where the formula also fixes which state the collision starts from (e + O2[X,vib=0] --> e + O2[X,vib=1]).

LXCat.AbstractCollision — Type
AbstractCollision{R}

A collision process. R is the type of the reaction field — what the process does — while the concrete subtype carries the process physics (mass ratio, threshold energy, statistical weight ratio) and is what dispatch keys on.

R is LXCatReaction for a database as parsed (raw LXCat label strings, not reliably parseable — see resolve) and PlasmaSpecies.ReactionFormula once a label map has been applied. So AbstractCollision{ReactionFormula} is the signature for anything needing real species, and an unresolved database cannot reach it by accident.

reaction is always the first field; with_reaction relies on that.

source
LXCat.CrossSection — Type
CrossSection{T,I}

One LXCat record: type (an AbstractCollision), comment, the updated timestamp and cross_section, an interpolation of the tabulated data over energy in eV. Calling cs(E) returns the cross section in m² at energy E, clamped at zero.

source
LXCat.LXCatReaction — Type
LXCatReaction(projectile, target, product=nothing)

The reaction of a collision as the database spells it: raw, unresolved LXCat label strings. An empty or whitespace-only product normalises to nothing.

LXCat state notation is not standardized — each database names its states its own way — so these strings are kept verbatim rather than parsed. Use resolve with a label map to turn them into a PlasmaSpecies.ReactionFormula.

LXCat.load_database — Method
load_database(filename; target=nothing, kwargs...) -> Vector{<:CrossSection}

Read every cross-section record in the LXCat file filename. The element type is the Union of the concrete record types present, so loops over the result are type-stable; annotate with AbstractVector{<:CrossSection}, not Vector{CrossSection}. With target given, keep only records whose target_label equals it. Other keyword arguments (extrapolation, cache_parameters) are passed to parse_string.

LXCat.parse_string — Method
parse_string(s; extrapolation=ExtrapolationType.None, cache_parameters=true) -> CrossSection

Parse one LXCat record (header, ----- separator, data, separator) into a CrossSection. The keyword arguments are passed to DataInterpolations.LinearInterpolation.

By default the cross section is not extrapolated: evaluating it outside the tabulated energy range throws. Pass e.g. extrapolation=ExtrapolationType.Constant or ExtrapolationType.Extension (linear) to allow it; ExtrapolationType is re-exported from DataInterpolations.

LXCat.product_label — Method
target_label(c) -> String
product_label(c) -> Union{String,Nothing}
projectile_label(c) -> String

Labels of a reaction, collision or cross section. For an LXCatReaction these are the raw database strings; for a resolved reaction they are rendered from the species, so they read in LoKI notation rather than the original database's spelling — see the round-trip note above _lxcat_keyword.

product_label is nothing for a process with no distinct product: elastic and momentum-transfer kinds, or an empty LXCat excited-state field.

LXCat.reaction_template — Method
reaction_template(db) -> String

Pasteable Julia source for a resolve map covering every distinct reaction_key in db, right-hand sides left blank. The map has to be written by hand, LXCat state notation not being parseable; this gives it a skeleton matching the database at hand.

source
LXCat.resolve — Function
resolve(x, reactions) -> x

Replace raw LXCatReaction labels with PlasmaSpecies.ReactionFormulas taken from reactions, a map from reaction_key pairs to formulas. Works on a collision, a cross section, or a whole database.

Map values may be ReactionFormulas or strings; parsing a string needs PlasmaSpecies loaded (the LXCatPlasmaSpeciesExt extension).

Throws if any entry is missing from the map, listing every gap at once, so a forgotten state cannot slip through as a rate coefficient that matches nothing downstream. missing_reactions and reaction_template check coverage up front.
